# SHAKH 2027 — UI/UX Phase 06

## Customer Experience

This phase adds a unified customer area without replacing the global marketplace shell.

### Sections
- Overview
- Orders
- Wishlist
- Notifications
- Wallet
- D_SH Points
- Referral & Share
- Profile / settings

### UX principles
- Same global shell as the marketplace.
- Tab/section navigation instead of a separate visual application.
- Mobile-first; horizontal section navigation on small screens.
- No mock customer/order/product/financial records.
- Empty states explicitly explain that the future source is Supabase.
- Referral sharing is only a browser-level share affordance at this stage; referral attribution is intentionally deferred to the Growth phase so no fake referral ID is introduced.
