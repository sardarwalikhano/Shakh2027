# SHAKH UI/UX — Phase 02: Global Shell

Implemented the application-wide visual shell:

- sticky global header
- Kurdish-first search experience
- desktop primary category navigation
- mobile search expansion
- account, notification, location and wishlist entry points
- responsive mobile bottom navigation
- desktop footer
- shared shell container and spacing
- focus-visible states
- reusable shell icon primitives

The shell is deliberately marketplace-oriented: discovery and search are primary, while the visual language remains SHAKH-specific rather than cloning another marketplace.
