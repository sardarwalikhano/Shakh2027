# SHAKH 2027 — UI/UX Design System v1

## Product direction
A discovery-first marketplace and delivery experience inspired by modern commerce UX patterns, including dense discovery, quick actions, promotional surfaces, and strong product imagery — without copying any specific brand's visual system.

## Brand language
- Primary action: SHAKH Orange `#F97316`
- Strong action: `#EA580C`
- Ink: `#111827`
- Muted text: `#667085`
- Background: `#F6F7F9`
- Surface: `#FFFFFF`
- Border: `#E7E9EE`
- Success: `#16A34A`
- Warning: `#D97706`
- Danger: `#DC2626`

## Shape system
- Small radius: 12px
- Medium radius: 16px
- Large radius: 24px+
- Product/content cards favor generous corners with minimal borders.

## Shadow system
Use subtle elevation. Avoid heavy neumorphism or excessive shadows. Shadows primarily separate floating UI from the page surface.

## Typography
Kurdish/Arabic first. Preferred stack:
`Noto Sans Arabic`, `Segoe UI`, `Tahoma`, `Arial`, sans-serif.

Hierarchy:
- Display: 48–56px desktop, 32–40px mobile
- Section title: 24–32px
- Body: 14–16px
- Meta: 11–13px

## Layout principles
- Mobile-first.
- RTL is the default document direction.
- Desktop uses wider content rails; mobile uses compact horizontal rhythm.
- Search and discovery remain close to the thumb/action zone on mobile.
- Use white space to separate modules rather than relying on borders everywhere.

## UX principles
1. Discovery before navigation depth.
2. Strong product imagery and prices are visually dominant.
3. Primary CTA is visually obvious and consistent.
4. Important actions require minimal interaction steps.
5. Loading, empty, error and success states are first-class UI states.
6. Accessibility focus states must remain visible.

## Mobile navigation
Five high-frequency destinations are reserved for bottom navigation. Secondary functionality belongs in contextual menus, profile areas, or page-level controls.

## SHAKH-specific signature
The design uses orange as an action signal, deep ink for trust/structure, and restrained surfaces. Dark panels are reserved for hero statements, operational focus, and selected high-priority contexts.
